


# CineBox – Đặt vé xem phim mini

CineBox là website **đặt vé**  *xem phim mini*, giúp người dùng tìm kiếm thông tin phim, xem lịch chiếu và đặt vé trực tuyến một cách nhanh chóng, tiện lợi.

## 1. Cấu trúc thư mục dự án

|Thư mục|Nội dung|Chú Thích|
| :---: | :---: | :---: |
|assets|Hình ảnh, poster phim |Lưu trữ tài nguyên
|src| Các file mã nguồn | Xử lý chức năng website |docs|Tài liệu dự án |Lưu hướng dẫn sử dụng|

## 2. Lệnh liệt kê toàn bộ dự án

```powershell
Get-ChildItem -Recurse -Force
```

## 3. Danh sách công việc

- [x]   Sắp xếp thư mục dự án
    
- [ ]   Upload dự án lên GitHub
    

## 4. Bảo vệ thông tin bí mật

> Không upload file .env lên GitHub.
